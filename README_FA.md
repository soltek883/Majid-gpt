# سایت معرفی مجیدی پی‌تی

این یک سایت کاملاً استاتیک است:
- فقط صفحه معرفی بات
- عکس پروفایل در پوشه `assets`
- دکمه «شروع چت با بات» که مستقیماً به `https://t.me/fastserver_shop_bot` می‌رود
- بدون API، بک‌اند، کلید API یا نصب وابستگی

## انتشار با GitHub Pages
1. فایل‌های داخل ZIP را در یک GitHub repository آپلود کن؛ خود ZIP را به‌جای محتویاتش آپلود نکن.
2. در ریپازیتوری برو به **Settings → Pages**.
3. در بخش **Build and deployment**، گزینه **Deploy from a branch** را انتخاب کن.
4. Branch را روی `main` و folder را روی `/ (root)` بگذار و Save کن.
5. پس از انتشار، GitHub یک آدرس Pages به تو می‌دهد.

فایل `index.html` باید در ریشه ریپازیتوری باشد و پوشه `assets` هم کنار آن قرار بگیرد.
